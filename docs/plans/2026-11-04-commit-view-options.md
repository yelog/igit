# Commit View Options Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add an IDEA-style view menu and clear folder icons to Commit while preserving checked items, repository scope, and Git content.

**Architecture:** Put display state and menu events in `src/commit/display.rs`, combining directory and repository grouping in the existing tree model. Obtain ignored items through read-only Git queries and display them separately as unselectable Ignored Files. Commits and AI always exclude them. Reuse the current palette, icon fallbacks, and mouse cell hit testing.

**Tech Stack:** Rust, Ratatui, Crossterm, system Git; no new dependencies.

---

### Task 1: Define display state and grouping

**Files:** Create `src/commit/display.rs`; modify `src/commit.rs`, `src/commit/tree.rs`; test `src/commit/tree.rs`.

1. Preserve the default layout with `Options { directories: false, modules: true, ignored: false, status: false }`.
2. Add real multi-repository tests for all four Directory / Module combinations, asserting leaf identity, selection, Roots filtering, and positioning after collapse.
3. With Module disabled, flatten all repositories. If Directory is also enabled, build the directory tree from workspace-relative paths.
4. Run `cargo test --locked commit::tree::`; expect all grouping combinations to pass.

### Task 2: Read-only display of ignored items

**Files:** Modify `src/commit/backend.rs`, `src/commit.rs`, `src/commit/tree.rs`, `src/commit/rows.rs`, `src/commit/view.rs`.

1. Run `git ls-files --others --ignored --exclude-standard --directory -z` to obtain native paths, keeping ignored directories as single items.
2. Add `Change::ignored()` and `Change::selectable()`. Exclude ignored items from all checking, commit, AI, and group-move paths.
3. Show Ignored Files only after a successful query. When disabled, remove read-only items while preserving checks and undo history for tracked/untracked files.
4. Test `.gitignore` / `.git/info/exclude`, ignored directories, stale checks, and read-only previews that do not read file content.

### Task 3: Menu, icons, and interaction

**Files:** Modify `src/commit/display.rs`, `src/commit/rows.rs`, `src/commit/view.rs`, `src/commit/keymap.rs`, `src/shell.rs`; test `src/commit/view_tests.rs`.

1. Add a toolbar eye dropdown, toggled by `o`; list Directory, Module, Ignored Files, and Git Status under Group By / Show.
2. Move with `j/k`, arrow keys, and the wheel. Space / Enter toggle immediately; Esc closes. The menu border intercepts underlying actions; clicking outside closes the menu and continues handling that click.
3. Use open/closed folder icons for ordinary repositories and directories, and a folder icon for ignored directories. Preserve a marker and readable name even when icon space is limited.
4. Validate menu layout and mouse hit testing at 44×12, 80×24, and 120×36 in all three icon modes. Preserve `t/s/v` shortcuts.

### Task 4: Documentation and regression checks

**Files:** Modify `README.md`, `docs/design.md`, `docs/prd.md`, `docs/architecture.md`.

1. Document that Module corresponds to a repository, along with defaults, session scope, read-only ignored items, and new menu keys.
2. Run `cargo test --locked commit::`; if needed, run full `cargo test --locked` to check Shell help and entry points.
3. Run `cargo fmt --all --check` and `cargo clippy --locked --all-targets -- -D warnings`.
4. In temporary repositories, check files with both staged and unstaged changes, unchecked staged files, and ignored items. Compare actual committed trees, the real index, and the worktree. Modify files only; do not commit or push in the development repository.

**Regression finding:** The previous Git exclude patterns generated by path depth could accidentally exclude selected leaves. Index queries now filter precisely by native path; other operations use escaped paths and exclusion patterns that must include descendants. Regression coverage also includes Chinese names, wildcards, backslashes, submodule updates/deletions, and isolation of unchecked descendants.
