# IDEA Git Log 对照实现计划

**目标：** 以用户的 IDEA Git Log 截图作为原生终端 Log 的布局、信息顺序和交互验收基准。

**实现边界：** 保留真实 Git 查询、跨仓隔离和其他三个工作面板；只用终端字符与颜色绘制。参考图的仓库、作者和路径是当前选择，不是默认值。技术栈为 Rust、Ratatui、Crossterm、系统 Git。

1. `src/log/model.rs`：让默认历史、引用、提交时间和图线取自实际 Git 对象；验证合并、相同 SHA 的多仓、stash 及筛选。
2. `src/log/refs.rs`：按 HEAD / Local / Remote / Tags 汇总引用，用路径层级代替每仓重复列表；验证同名分支与搜索、收展。
3. `src/log/inspector.rs`：文件按仓库和目录展示计数；详情按标题、身份与时间、包含分支排列，保留补丁和父提交入口。
4. `src/log.rs`、`src/shell.rs`：对齐顶部页签、单行筛选、三栏比例与选中色，重画提交行和右端引用；按钮、分隔线用实际绘制坐标命中，保留窄屏单栏。
5. 在临时多分支仓库检查宽屏、120×36 和 80×24 的实际画面与键鼠操作。运行 `cargo test --locked`、`cargo fmt --all --check`、`cargo clippy --locked --all-targets -- -D warnings`，并同步 README、交互设计及验收文档。
