# IDEA Push Tool Window Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Match the user's IDEA Push screenshot with an aligned repository list, a collapsible file tree with change colors, and a right pane shown in full by default.

**Architecture:** Preserve existing push planning, review, and background execution boundaries. Change only Push's read-only preview, rendering, and event handling. Read change types using Git's NUL-delimited name-status output; tree nodes retain raw PathBuf values and file indices. Separate visible tree rows from actual files to avoid opening the wrong file after collapsing.

**Tech Stack:** Rust, Ratatui TestBackend, Crossterm, system Git; reuse existing icons, display-width handling, and IDEA palette without new dependencies.

---

### Task 1: Change types and file tree

**Files:** Create `src/push/files.rs`; modify `src/push.rs`.

1. Add tests for directory compaction, descendant counts, collapsed navigation, duplicate filenames, and non-UTF-8 paths. Run `cargo test --locked push::files::` and confirm that the new behavior still needs implementation.
2. Use `git diff --name-status -z --find-renames` and `diff-tree --root --first-parent -m` to read batches and individual commits. Mark tree files as added for new targets. Retain source paths for renames; restrict Diff to both the old and new paths.
3. Implement the "repository → content root → compacted directory → file" tree, expansion/collapse, and mapping from visible rows to original file indices. Rerun targeted tests and expect them to pass.

### Task 2: IDEA repository columns and right pane

**Files:** Create `src/push/view.rs` and `src/push/view_tests.rs`; modify `src/push.rs`.

1. Add TestBackend tests: repository names of different lengths, wide Unicode characters, long branches, submodule labels, and result markers must align to shared column starts in all three icon modes. Narrow-screen control hit testing must remain correct.
2. Calculate repository, source branch, arrow, target, outgoing count, and submodule columns in actual cells. Truncate overlong text within its own column. Use IDEA blue for remote targets.
3. Let the file tree fill the right pane by default; provide toolbar actions for toggling details and expanding/collapsing all. Keep type colors for file icons; use green/blue/red/amber filenames for added/modified/deleted/renamed files, retaining text statuses.
4. Connect mouse input and `j/k`, `h/l`, `Enter`, `d`, `Esc`. Open Diff/container summaries on demand, returning to the same tree row when details close. Run `cargo test --locked push::`; expect success with existing review and retry tests unchanged.
