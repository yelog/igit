# Stash Tab Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Browse every repository's stash entries with saved timestamps, a changed-file tree, and Log-style read-only Before/After comparisons.

**Architecture:** `StashPanel` owns repository lists, folding, selection, and asynchronous snapshot loading. A narrow `log::snapshot` adapter reuses Log's actual inspector, revision reader, and Diff overlay without loading history or exposing Log filters. Stash entries retain immutable object IDs; tracked files compare the first parent to the saved worktree, and saved untracked files compare an empty side to the third-parent snapshot. Global Roots applies, including repositories without stashes.

**Tech Stack:** Rust, Ratatui, Crossterm, system Git; existing dependencies only.

---

### Task 1: Read stash snapshots and reuse historical previews

**Files:** Create `src/stash/model.rs`, `src/log/snapshot.rs`; modify `src/log.rs`.

1. Read stash reflog entries with NUL-separated object IDs, selectors, timestamps, and subjects. Keep errors local to their repository.
2. Load tracked and saved untracked changes from immutable trees. Reuse the exact Log file tree and two-way comparison, including binary/large-file patch fallbacks and file navigation.
3. Cover staged plus unstaged content, deletions, saved untracked files, unusual filenames, stash index renumbering, and unchanged HEAD/index/worktree/reflog in temporary repositories.
4. Run `cargo test --locked stash` and address failures.

### Task 2: Add the Stash panel and shell integration

**Files:** Create `src/stash.rs`, `src/stash/view.rs`, `src/stash/preview.rs`, `src/stash/tests.rs`, `src/shell/stash_tests.rs`; modify `src/lib.rs`, `src/shell.rs`, `src/shell/workspace.rs`, `src/shell/panes.rs`, `src/config.rs`, `src/config/keys.rs`, `config/default.toml`, `src/ui/help.rs`, `src/ui/panes.rs`.

1. Display expanded repository groups with newest-first stash rows, saved dates and times, empty/error states, keyboard navigation, and mouse hit areas.
2. Load the selected file tree after navigation settles; discard stale results on selection, refresh, or Roots changes.
3. Add the Stash header and `6` shortcut, contextual/remappable controls, pane focus/resize/maximize, refresh on entry/F5/focus, and Diff input guards.
4. Test tab routing, Roots, empty repositories, stale previews, exact Diff content, and 120×36, 80×25, and 44×12 layouts.

### Task 3: Document and validate

**Files:** Update `README.md`, `docs/prd.md`, `docs/design.md`, `docs/architecture.md`, `docs/configuration.md`; adjust shell header expectations.

1. Document browsing, timestamps, preview semantics, and controls. This feature performs no stash apply/pop/drop/create operations.
2. Run `cargo test --locked`, formatting checks on changed files, and `cargo clippy --locked --all-targets -- -D warnings`.
3. Review the diff and preserve all pre-existing work. Do not commit or publish.
