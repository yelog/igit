# Log Commit Graph: Compact Lanes with Continuous Connections

**Goal:** Within the same repository and reference scope, follow a commit's lines to its parents as in IDEA. Graph width should reflect histories that are running in parallel.

**Diagnosis:** The first reference image sets repository Paths, while the second combines 11 Roots. Three rendering issues remain even within a single repository: the first parent always takes a new current lane even if a lane already leads to the same object; the model's 12-lane window and the view's 8/14-character window each move with every row's node; the node dot replaces the entire vertical-line character at its position.

1. In `src/log/model/graph.rs`, resolve visible parents by repository + SHA. Record each lane's occupied start/end rows, forks, and joins. Reuse lines already leading to the same parent, preserve a continuous first-parent path for the mainline, and explicitly draw bends that converge into empty columns.
2. In `src/log/view.rs`, select one horizontal window per screen. Reserve title space based on terminal width, distinguish offscreen lines from offscreen nodes, and keep one row per commit. Center nodes on their lanes; on terminals with branch-graph glyph support, draw dots and lines in the same cell using their actual connection directions.
3. Check lanes with common ancestors, repeated merges, interleaved repositories, filtered-out parents, and more than 12 parallel histories. Inspect actual Ratatui cells when selecting distant columns and resizing the window; verify that the same line aligns across adjacent rows.
4. Run `cargo test --locked log::`, `cargo test --locked`, `cargo fmt --all --check`, and `cargo clippy --locked --all-targets -- -D warnings`. Update the interaction guide with explicit Paths steps for reproducing a single-repository comparison. Use temporary directories for test repositories.
