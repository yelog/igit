# Log 提交图：收紧轨道，保持连线

**目标：** 在相同仓库和引用范围内，能像在 IDEA 中一样从一条提交沿线找到父提交；宽度反映正在并行的历史。

**诊断：** 对照图一设置了仓库 Paths，图二则合并了 11 个 Roots。限定同仓后还存在三个绘制问题：第一父提交总是新占当前轨道，即使已有轨道通往同一对象；模型的 12 轨窗口和视图的 8/14 字符窗口分别按每一行的节点移动；圆点替换了节点所在的整个竖线字符。

1. 在 `src/log/model/graph.rs` 用「仓库 + SHA」解析可见的父提交。记录轨道占用的起止行、分叉与汇合；复用已通往同一父提交的线，给主线留出连续的第一父路径，明确画出向空列收拢的转折。
2. 在 `src/log/view.rs` 为一屏选择一次横向窗口。按终端宽度为标题留出空间，越界的线与越界的节点使用不同提示；一条提交仍占一行。节点居中在轨道上，支持分支图字形的终端按真实连接方向把点和线绘在同一格。
3. 用共同祖先、多次合并、交错仓库、被筛掉的父提交和超过 12 条并行历史检查轨道。用 Ratatui 实际字符格检查选择远列和改变窗口宽度，检查相邻行的同一条线是否对齐。
4. 运行 `cargo test --locked log::`、`cargo test --locked`、`cargo fmt --all --check` 和 `cargo clippy --locked --all-targets -- -D warnings`。更新交互说明，写清重现单仓对照的 Paths 操作；测试仓库使用临时目录。
