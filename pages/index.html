IGit

A terminal workspace for your Git repositories. Open it with igit or ig.

Source and documentation · Release downloads

macOS and Linux

Install the beta channel on Intel/Apple Silicon macOS or x86_64/ARM64 Linux. Requires Python 3.9+, curl, and Git.

curl -fsSL https://igit.yelog.org/install-beta.sh | sh

For the stable channel, use install.sh. A channel becomes available after its first release.

Windows x86_64

Run in PowerShell, then open a new terminal. Git and curl must be available.

$env:IGIT_CHANNEL = 'beta'
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://igit.yelog.org/install.ps1.txt -ErrorAction Stop | iex"

Update

igit update --check
igit update

Native installations retain their release channel. Use --channel stable or --channel beta to switch explicitly. If your installed version predates this command, rerun its installer to update.
